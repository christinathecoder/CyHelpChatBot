# 🛡️ CyHelp - Interactive Cybersecurity Chatbot

CyHelp is a terminal-based interactive Python chatbot designed to teach users the basics of cybersecurity. This project was developed as part of the **Girls Who Code Summer Pathways Program** and uploaded to GitHub to showcase interactive terminal applications.

It takes users on a brief journey through the history of the field and breaks down the core pillars of the **CIA Triad** (Confidentiality, Integrity, and Availability).

---

## 🚀 Features

*   **Interactive Conversation:** Greets users by name and calculates the exact age of the cybersecurity industry based on the current year.
*   **Educational Deep-Dive:** Includes a built-in menu system allowing users to explore the components of the CIA Triad at their own pace.
*   **Terminal-Optimized:** Built specifically to run flawlessly inside any standard command-line interface or integrated terminal.

---

## 🛠️ Prerequisites

Before running the application, make sure you have the following installed:
*   [Python 3.x](https://python.org)
*   [Visual Studio Code (VS Code)](https://visualstudio.com)

---

## 🏃 How to Run the Project in VS Code

Follow these simple steps to start chatting with CyHelp:

1. **Open the Project Folder:** Launch VS Code, go to `File > Open Folder...`, and select the folder containing this project.
2. **Open the Script:** Click on the `cyhelp.py` file in the sidebar to display the code.
3. **Run the Code:** 
   * Click the **Play Button** (Run Python File) in the top-right corner of the VS Code window.
   * *Alternatively:* Open a built-in terminal (`Ctrl + \``) and type:
     ```bash
     python cyhelp.py
     ```
4. **Interact:** Click inside the terminal panel at the bottom of your screen where the prompt appears, type your answers, and press **Enter**!
